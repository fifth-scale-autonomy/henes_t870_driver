# henes_t870_driver
#### 1/5 스케일 HENES T870 차량용 ROS 2 드라이버 — AckermannDrive 명령을 아두이노 제어기 시리얼 프로토콜로 변환하고 조향·속도·기어·모드 피드백을 발행
#### ROS 2 driver for a 1/5-scale HENES T870 vehicle — converts AckermannDrive commands to the Arduino controller's serial protocol and publishes steering, speed, gear and mode feedback.
